# 01 카페 업무 규칙

> 코드 위치: `tablet-kiosk-core/apps/kiosk/lib/verticals/cafe/`. 확장 지점 정의는 core `docs/08-vertical-module.md`.

## 업무 규칙

### 1. 음료 옵션

- 메뉴를 누르면 옵션 화면 (`02-option`): 온도 → 사이즈 → 샷 → 시럽 → 얼음 양 → 컵 → 수량 → `5,800원 담기`
- 가격 표시는 톨 기준, 옵션 추가금 합산
- ICE ONLY 메뉴는 온도 선택 없이 ICE 고정
- 같은 메뉴라도 옵션이 다르면 장바구니에 별도 줄

### 2. 스탬프 (카페 전용)

- **음료 1잔 = 스탬프 1개**, 푸드는 적립 안 함 (`stamp_eligible`)
- 10개 → **아메리카노 톨 1잔 무료 쿠폰** 자동 발급, 스탬프는 0개부터 다시
- 결제 전 전화번호 입력 화면 (`05-stamp`): 숫자 키패드, 현재 스탬프 `7 → 10 / 10` 미리보기
- 처음이면 그 번호로 바로 가입 — **개인정보 수집 · 이용 동의 필수** (번호는 스탬프 적립과 쿠폰 발송에만 사용)
- `적립 안 함` 선택 시 적립 없이 결제
- 무료 쿠폰은 다음 주문 때 전화번호 또는 쿠폰 시리얼로 사용 (문자 발송은 2차)

### 3. 더치페이 적립

- 결제자마다 각자 번호로 적립
- **메뉴별**: 결제자가 고른 음료 잔 수만큼 적립
- **N등분 · 금액**: 음료 잔 수를 결제 순서대로 배분 (예: 3잔 2명 → 2 / 1)
- 결제자 행에 마스킹 번호 `010-****-1111 · 스탬프 +1` 표시

### 4. 바리스타 주문서

- 맨 위 `C-042 매장` (2배 크기)
- 음료 줄 아래 옵션 들여쓰기 (`· 얼음 보통 · 매장 컵`)
- 마지막 줄: `스탬프 +3 · 전체결제 접수 09:12`

### 5. 개인정보

- 전화번호는 암호화 저장 + 조회용 해시 분리, 화면 · 영수증 · 로그에는 마스킹(`010-****-5678`)만
- 동의 문구 · 보관 기간 · 파기 절차를 개인정보 처리방침에 반영 (출시 전 확인)

## 확장 지점 구현

| 확장 지점 | 카페 구현 |
|---|---|
| `theme` | 브라운 테마 |
| `preset` | 추천 · 에스프레소 · 콜드브루 · 블렌디드 · 티 · 푸드 + 위 예시 메뉴 · 옵션 |
| `labels` | `주문번호`, 완료 문구 "음료가 준비되면 번호를 불러 드려요" |
| `menuCardDecorator` | 온도 표시(HOT · ICE / ICE ONLY), 상단 "스탬프 10개 = 커피 1잔" 안내 |
| `itemConfigurator` | 음료 옵션 화면 |
| `paymentHooks.beforePart` | 전화번호 입력 · 동의 (선택) |
| `paymentHooks.afterPart` | 결제자별 스탬프 적립 |
| `paymentHooks.afterPaid` | 10개 달성 시 무료 쿠폰 발급 |
| `printBlocks.kitchen` | 옵션 강조 바리스타 주문서 |
| `printBlocks.receipt` | 스탬프 현황 줄 |
| `doneScreenExtras` | 스탬프 현황 `10/10`, 쿠폰 발급 안내 |
| `setupExtras` | 스탬프 규칙 (1잔 = 1개, 10개 = 아메리카노 1잔, 쿠폰 유효기간, 쿠폰 문자 서비스) |
| `adminExtras` | 스탬프 회원 목록 (2차) |

정의하지 않은 확장 지점은 기본 구현(아무것도 안 함)을 씁니다.

## 데이터 키 (`vertical_attrs` · `vertical_data`)

| 위치 | 타입 | 뜻 |
|---|---|---|
| `menu_items.vertical_attrs.temperature` | "both" | "ice_only" | "hot_only" | 온도 선택 제한 |
| `menu_items.vertical_attrs.stamp_eligible` | bool | 스탬프 적립 대상 (음료 true, 푸드 false) |
| `order_items.options_snapshot` | json | 온도 · 사이즈 · 샷 · 시럽 · 얼음 · 컵 |
| `orders.vertical_data.stamp` | json | 결제자별 적립 내역 요약 (전화번호 원문 금지) |

새 키를 추가하면 이 표를 먼저 고칩니다. 조회 · 집계가 많아지면 core에서 컬럼으로 승격합니다.
